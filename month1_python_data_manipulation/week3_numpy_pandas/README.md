# Week 3 – NumPy and Pandas for Data Manipulation

## Overview
This project focuses on using NumPy and Pandas for data manipulation, cleaning, and basic analysis.

## Tasks Completed
- Created and analyzed NumPy arrays
- Loaded a CSV dataset using Pandas
- Identified missing values
- Removed duplicate records
- Filled missing values using mean values
- Created a new calculated column: TotalSales
- Grouped data by category, city, and product

## Concepts Covered
- NumPy arrays
- Mean, minimum, maximum, and standard deviation
- Pandas DataFrames
- Reading CSV files
- Handling missing values
- Removing duplicates
- GroupBy operations
- Basic data aggregation

## How to Run
cd week3_numpy_pandas  
python week3.py

## Outcome
This project helped build practical data manipulation skills using NumPy and Pandas. It demonstrates how raw sales data can be cleaned, transformed, and analyzed for business insights.
