# Week 1 – Python Basics

## Overview
This project demonstrates fundamental Python programming concepts including variables, data types, input/output operations, conditional statements, and loops.

## Programs Implemented
1. Temperature Converter
2. Basic Calculator
3. Sum of Numbers using Loop
4. Average Temperature Calculator (Client Project)

## Concepts Covered
- Variables and Data Types
- Conditional Statements (if-else)
- Loops (for, while)
- Functions
- User Input Handling
- Basic Data Validation

## How to Run
1. Open terminal
2. Navigate to folder:
   cd week1_basics
3. Run:
   python week1.py

## Outcome
This project helped build a strong foundation in Python programming and logical problem-solving, which is essential for data analysis tasks.
