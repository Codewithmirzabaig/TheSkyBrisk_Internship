# Week 4 – Data Visualization with Matplotlib and Seaborn

## Overview
This project focuses on creating visualizations using Matplotlib and Seaborn to analyze sales data and identify patterns.

## Tasks Completed
- Loaded and cleaned sales data
- Created histogram for Total Sales distribution
- Created scatter plot for Quantity vs Total Sales
- Created bar chart for Total Sales by Category
- Created heatmap to show correlation between numeric variables

## Concepts Covered
- Matplotlib plots
- Seaborn heatmaps
- Data visualization
- Exploratory data analysis
- Saving plots as image files

## Output Files
The generated visualizations are saved inside the plots folder:
- histogram_total_sales.png
- scatter_quantity_sales.png
- bar_total_sales_category.png
- heatmap_correlation.png

## How to Run
cd week4_visualization  
python week4.py

## Outcome
This project helped visualize data relationships and business insights using Python visualization libraries.
