# Month 1 – Python Basics and Data Manipulation

## Overview
This project demonstrates foundational skills in Python programming, data manipulation, and data visualization developed over four weeks.

## Week 1: Python Basics
Implemented core Python programs including temperature converter, calculator, loops, and average temperature script.

## Week 2: Data Structures & Functions
Worked with lists, dictionaries, sets, and functions. Built a data cleaning script to remove duplicates and filter data.

## Week 3: NumPy & Pandas
Performed data cleaning, handled missing values, and conducted data aggregation using Pandas and NumPy.

## Week 4: Data Visualization
Created visualizations including histogram, scatter plot, bar chart, and heatmap using Matplotlib and Seaborn.

## Key Skills Gained
- Python programming
- Data cleaning and preprocessing
- Data analysis using Pandas
- Data visualization
- Problem-solving and logical thinking

## Outcome
Developed an end-to-end data processing workflow from raw data to visualization, demonstrating readiness for data analysis tasks.
