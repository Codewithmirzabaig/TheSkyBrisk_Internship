# Flight Delay Prediction

## Files
- `Flight_Delay_Prediction.ipynb`: Complete machine learning notebook
- `Model_Evaluation_Report.md`: Evaluation report template
- `requirements.txt`: Python package requirements

## Setup
1. Download the Airline Delay Dataset from Kaggle.
2. Rename the CSV file to `Airline_Delay_Dataset.csv`, or update `DATA_PATH` in the notebook.
3. Place the CSV in the same folder as the notebook.
4. Install dependencies:
   `pip install -r requirements.txt`
5. Run all notebook cells.

## Outputs Created After Running
- `flight_delay_model.pkl`
- `model_evaluation_results.csv`
- `classification_reports.txt`

The notebook automatically attempts to identify common date and target column names.
